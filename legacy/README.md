# Legacy 文件

此目录包含已废弃的文件，保留用于参考。

## 文件说明

### etf_stats_aggregation.py
多策略 ETF 统计聚合脚本。已废弃，因为：
- 使用旧的 `APIKey.json` 配置方式
- 需要多个不同的 API 密钥，不适合单一 `.env` 文件
- 功能已被其他监控工具替代

### hedging_aggregation.py  
多策略对冲聚合脚本。已废弃，因为：
- 使用旧的 `APIKey.json` 配置方式
- 需要多个不同的 API 密钥
- 对冲功能已整合到各策略的 `hedging.py` 中

## 如需使用

如果需要重新启用这些脚本，请：
1. 将代码迁移到使用 `.env` 环境变量
2. 或者为多策略场景设计新的配置方案
